# Autonomous data research
User intent: a question alone should drive approach selection, source discovery, assessment, acquisition, calculations and presentation. Existing approval of the interpreted scope remains; no source must be manually supplied. Broader Europe means explicit country coverage, never implicit EU equivalence.

Design: extend model question interpretation with an optional executable research strategy (literature, data, both). At execution use the selected OpenAI model with Responses web search to discover candidate dataset pages. Record search citations, query actions, source decisions and model usage. Never use model-supplied numerical observations. Download only public HTTP(S) resources observed in search or in retrieved page links, with DNS/redirect/size limits. No generated code execution.

Supported execution: EFFIS's checked workbook adapter when independently discovered; generic long-form CSV annual series using a validated declarative column/filter mapping. Missing is distinct from zero, duplicate entity/year rows fail rather than silently aggregate, units remain explicit, no automatic sums of non-additive metrics. Model source assessments are labeled as such, with retained metadata, raw files and mappings. Unsupported sources are recorded as blocked; they do not become a successful numerical answer.

For combined requests run the existing literature pipeline and show its grounded findings separately from data-derived observations. Data failure never masquerades as success; combined runs may retain useful literature with a visible data gap. Downloads preserve both branches and source provenance. Search tool access requires the selected OpenAI model; other providers retain existing literature/curated workflows and expose unavailable capability.

Validation: source citation enforcement, URL safety, parsing and schema failures, missing data/zero, duplicate rejection, unit conversion whitelist, country filtering, deterministic offline replay, automatic strategy integration, data-only and combined execution, failure visibility, browser charts and model provenance, existing regression suite. Live wildfire acceptance run must actually search before selecting EFFIS. A different-topic test must exercise generic tables.
