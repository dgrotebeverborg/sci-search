# GPT comparison protocol — 2026-09-28

Approved scope: the assistant supplies questions, reference evidence, expectations, execution and review. No user scoring work is required. This is an exploratory evaluation, not an independently validated scientific benchmark.

1. Ten interpretation questions, four named models, three repeats: 120 outputs. Use the current app prompt/schema and deterministic suggestions without changing them between models. GPT-4.1 mini uses current controls; GPT-6 uses medium reasoning, no temperature and 8,000 max completion tokens (transport compatibility adaptation only). Freeze inputs and code hashes before substantive calls.
2. Three identical fixed evidence packets (linguistic diversity, green space/diabetes, biochar/yield), four models, three repeats: 36 analyses, each using the actual app generation, quote validation and semantic support review. Use real source excerpts with explicit abstract/full-text provenance, plus deliberately irrelevant evidence where available. Hand-selected packets are not comprehensive literature reviews.
3. Shuffle and hide model identity for qualitative appraisal. Reviewer reads questions, source passages and prewritten expectations, never the identity key. Review all interpretations for meaning and all final analyses for support and omissions. Automated role/keyword checks are diagnostics: semantically equivalent terms or a measurement faithfully embedded in the subject do not count as scientific failures. Score interpretation faithful/unfaithful with reasons. Score fixed analyses on grounding, relevance, evidence coverage and appropriate caution (0=poor, 1=partial, 2=good each); flag unsupported causal/scope/numerical claims separately. Withholding everything is safe but not a useful synthesis and loses coverage points. A second model assisting review is not human scientific validation.
4. Choose two models by qualitative fidelity and absence of major unsupported assertions, then useful coverage, then measured cost. Desired gates: >=90% faithful interpretations and no major unsupported final claims; if none pass, report that honestly and still compare the two most informative candidates. No statistical-significance claims from three repeats.
5. Run each finalist through actual search, acquisition, screening, extraction and synthesis for the two user questions and biochar. Same finite budgets, isolated output folders, no shared scientific memory, save discovered records and outcomes. Interpret each question with the selected model. Do not forcibly approve material ambiguities. Separate retrieval/acquisition failure from model failure. Complete searches are bounded exploratory reviews, not exhaustive systematic reviews.
6. Keep an append-only per-call ledger of sanitized request, response/model ID, tokens (including cached inputs, cache writes and reasoning), latency and API error. No silent retries/fallback successes; record rule fallback separately. USD calculations use current standard short-context prices; account invoice is authoritative. Initial GPT cost ceiling $15, conservative reservations; stop new calls if provider timeout leaves unknown billing. No app default changes or user-run overwrites.

Final deliverable: reproducible references and results, measured costs, failure examples, stage-specific recommendation, limitations, and whether any app compatibility changes are needed. Report synthetic logic tests separately from live benchmark findings.
